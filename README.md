# Uki's Bike Log

Aplikacja działa pod adresem: https://lukaszdudzinski.github.io/uki-bike-log/

**Kod jest rozwijany w prywatnym repozytorium `ukis`** (folder `apps/bike-log`). To repozytorium służy wyłącznie do publikacji: gałąź `pages` zawiera gotowe pliki aplikacji, które workflow „pages” publikuje na GitHub Pages. Gałąź `main` przechowuje historię kodu sprzed przeniesienia (2026-10).

Nie wprowadzaj zmian w tym repozytorium. Nowe wersje publikuje workflow „Publikuj” w repozytorium `ukis`.
